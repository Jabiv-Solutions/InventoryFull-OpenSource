**Inventory Full** es un sistema ERP de escritorio y Punto de Venta (POS) pensado para pequeñas y medianas empresas. Permite gestionar ventas, inventario, cierres de caja, gastos operativos y créditos en tiempo real con un potente motor **multidivisa** (Dólares, Bolívares y Pesos Colombianos).

---

## 🔥 Características Principales

- 💳 **Punto de Venta (POS) Multidivisa:** Cobro simultáneo en $, Bs y COP con conversión e integración de tasas en tiempo real.
- 📦 **Control de Inventario:** Gestión de existencias, precios de compra/venta, cálculo de margen unitario y total, y alertas de stock mínimo.
- 📊 **Cierre de Caja y Balance:** Desglose detallado por tipo de pago (Efectivo/Transferencia) y moneda.
- 📝 **Control de Créditos y Apartados:** Seguimiento de saldos pendientes y registro histórico de abonos.
- 📈 **Módulo de Finanzas:** Registro de gastos operativos (OpEx) y cálculo del Punto de Equilibrio.
- 📑 **Exportación e Impresión:** Generación de órdenes de despacho/tickets e historial en hojas de cálculo Excel.

---

## 🛠️ Tecnologías Utilizadas

- **Backend:** Python con FastAPI y base de datos SQLite.
- **Frontend:** HTML5, JavaScript (ES6+), Tailwind CSS y Lucide Icons.
- **Desktop Wrapper:** PyWebView para interfaz nativa de escritorio.
